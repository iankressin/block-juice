Caveats

  • Native ETH only. ERC-20 tokens such as WETH are not counted.
  • The figure is rounded to 6 decimals. results/tracked_wallets_eth_by_wallet.csv has each balance in wei.

Reproduce it

The analyses behind the numbers 
-- transformation/analyses/tracked_wallets_eth.sql
select round(sum(balance) / 1e18, 6) as eth
from "warehouse"."analytics"."latest_balances"
where chain = 'ethereum' and asset_type = 'native'

-- transformation/analyses/tracked_wallets_eth_by_wallet.sql
select
    wallet,
    block_number,
    round(balance / 1e18, 6) as eth,
    balance as wei
from "warehouse"."analytics"."latest_balances"
where chain = 'ethereum' and asset_type = 'native'
order by balance desc
