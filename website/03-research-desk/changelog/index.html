Changelog

What changed, by day

BlockJuice has no version numbers yet: the framework is the repository, and main is what you run. Each entry links to the pull request that landed it.

Kinds

Added a new source, mart, command or workflow. Changed something that was already there, including renames you may need to follow. Fixed a defect. Docs words only.

2026-11-0619 pull requests
  • Added

    The evm-erc20-metadata source reads each token's name, symbol and decimals on any EVM chain, and the tokens pipeline builds analytics.tokens from it. Old tokens that answer in bytes32 are read too.#21

  • Added

    The coinbase-candles source loads candles from Coinbase Exchange, laid out like binance-candles. analytics.token_prices now unions both exchanges.#22

  • Changed

    bj new-source can copy evm-erc20-transfers, so a new stream source starts from a working one.#20

  • Added

    The evm-chainlink-price-feeds source loads Chainlink rounds on Ethereum, Arbitrum and Base. The prices pipeline builds analytics.oracle_prices, and a warn test flags feeds that fell silent for two heartbeats.#18

  • Changed

    base-op-standard-bridge became evm-op-standard-bridge, so it can load any OP-stack chain from a chains/<chain>/ folder.#19

  • Added

    The binance-candles source and the prices pipeline. analytics.token_prices holds one row per candle of a token against its quote asset.#17

  • Changed

    classified_transfers is now a mart in the transfers pipeline. It labels each side of a transfer as exchange, deposit address, contract, EOA or bridge, and gives the transfer a category.#16

  • Added

    bj install sets up a fresh checkout and bj dev starts the Docker stack, runs the doctor checks and starts Dagster, in one line.#15

  • Changed

    The Ethereum sources became evm-* packages that load any EVM chain. Each chain keeps its own RPC URL, start block and addresses.json under chains/<chain>/.#14

  • Docs

    A public README and docs/architecture.md: what ships, the quick start, the data flow and how to add a source or a pipeline.#13

  • Added

    The transfers pipeline follows any token on Arbitrum and Base, set up for UNI.#4

  • Changed

    The skill's new-pipeline workflow was refreshed and a schedule-jobs workflow added, so /bj schedule <pipeline> <cron> changes when a pipeline runs.#11

  • Added

    bj doctor runs preflight checks on the env files, the warehouse, the RPC gateways and the tools before you start debugging.#12

  • Docs

    The call-source checklist and how a stream source fails and resumes.#8

  • Changed

    ingestion/sources.json is generated from the packages, and Dagster builds its ingestion assets from it. A source cannot ship without an asset.#10

  • Added

    A Dshackle healthcheck and Prometheus alert rules for the RPC gateways.#9

  • Changed

    The report workflow now covers the whole path from a question to a shareable XLSX, PDF, Word or Google Doc, with rows from your warehouse.#7

  • Fixed

    Contracts on the Uniswap trade intermediates, so a malformed Swap fails the build instead of reaching dex_trades.#6

  • Changed

    ERPC_URL was renamed to EVM_RPC_URL, beside SOLANA_RPC_URL. Update your .env.#5

2026-11-04Foundation
  • Added

    The dex pipeline: analytics.dex_trades from Uniswap v2, v3 and v4, one row per trade, with each version's sign rule in its own intermediate model.

  • Added

    Stream sources for Uniswap v2, v3 and v4 that load pool creations and Swaps of pools trading a token list, each version in its own raw table.

  • Added

    bj blocks turns a date range into block ranges for any EVM chain in SQD Portal's registry, and question.yaml carries a block range per chain.

  • Added

    A protocol catalog under catalog/protocols/: contracts, events and ABIs proven on real logs before anyone writes SQL.

  • Docs

    The skill says what each ELT layer does, and asks for an address the repo does not hold instead of guessing one.
