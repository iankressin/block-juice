3Caveats

  • Staked SOL is not counted. Only the wallets' liquid balance is.
  • A Solana RPC serves only current state, so each run adds a new reading keyed by the slot it read. block_number in the mart is the slot.
  • results/tracked_wallets_sol_by_wallet.csv has each balance in lamports.

4Reproduce it

The analyses behind the numbers 
-- transformation/analyses/tracked_wallets_sol.sql
select round(sum(balance) / 1e9, 9) as sol
from "warehouse"."analytics"."latest_balances"
where chain = 'solana' and asset_type = 'native'

-- transformation/analyses/tracked_wallets_sol_by_wallet.sql
select
    wallet,
    block_number,
    round(balance / 1e9, 9) as sol,
    balance as lamports
from "warehouse"."analytics"."latest_balances"
where chain = 'solana' and asset_type = 'native'
order by balance desc
