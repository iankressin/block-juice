Analysis

Posts you can rerun

Every post here starts as an answer folder in the repo: a question, the marts it reads, the dbt analyses that select the result, and the checks that ran before it shipped. The page is the answer.md with its figures, provenance and SQL attached.

How a post is made

One question. question.yaml pins the definitions and the window: a chain, a block or a range.

One or more analyses. dbt analyses select the result from marts. The first row and column can be the value.

Checks before it ships. bj answer runs the tests upstream of the analyses and counts the dead letters of every input.

A file you own. answer.json, answer.md and results/*.csv, then a PDF, a spreadsheet or a Google Doc.
